# Ali Majed Dandash — Portfolio

Professional bilingual portfolio for a full-stack product engineer building mobile, web, backend, and data-driven systems.

**Live site:** [ali-dandash-portfolio.onrender.com](https://ali-dandash-portfolio.onrender.com/)

## What the portfolio shows

- Six product case studies with verified platforms, programming languages, data stores, and backend technologies
- Detailed architecture, security, evidence, technical challenges, and current boundaries for each audited project
- English and Arabic content with RTL support
- Commercial evidence including Daftr, a system sold to a grocery store and used daily
- Professional profile covering Zouzou client work, completed AI studies, and independent network operations supporting approximately 300 active subscribers
- Direct email, WhatsApp, LinkedIn, GitHub, and downloadable Full-Stack CV
- Responsive layouts for desktop, tablet, and mobile

## Technology

- Next.js-compatible application surface built with vinext
- React and TypeScript
- Responsive CSS with English and Arabic typography
- Cloudflare Worker-compatible production build
- Render deployment configuration
- Node test validating server-rendered portfolio output

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by the development server.

## Validate

```bash
npm run build
npm test
```

## Repository structure

```text
app/
  layout.tsx       Metadata and root document
  page.tsx         Home route
  portfolio.tsx    Portfolio content and interaction
  globals.css      Responsive visual system
public/
  assets/          Project screenshots, icons, and portrait
  downloads/       Public CV and approved downloads
tests/             Rendered-output verification
```

## Privacy and publishing boundaries

- Client code, credentials, API keys, private repositories, and customer data are not published here.
- Project claims distinguish verified implementation from incomplete or unaudited scope.
- Screenshots and downloads must be reviewed before publishing to avoid personal or client information.
- The portfolio has no visitor account requirement and no ChatGPT sign-in integration.
